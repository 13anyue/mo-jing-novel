## 快速开始（小白教程）

### 第一步：打开项目

1. 解压 `ai-visual-novel-v6.zip`
2. 双击 `index.html`，或在浏览器中打开它
3. 如果提示"是否允许存储"，请点击"允许"（用于保存你的数据）

### 第二步：配置AI接口

1. 点击「API设置」页面
2. 选择你的AI服务商（OpenAI / Claude / 百度文心 / DeepSeek / 自定义）
3. 填入 API Key 和 Base URL
4. 点击「保存设置」→「测试连接」

### 第三步：创建你的世界

1. 回到首页，点击「开启新篇」
2. 跟随4步向导：
   - **第1步**：输入世界观描述（或让AI生成）
   - **第2步**：AI辅助生成世界观详情
   - **第3步**：设置你的玩家身份（名字、性别、职业）
   - **第4步**：设置主要角色（让AI从世界观中提取）

### 第四步：开始游戏

1. 点击「开始游戏」进入运行界面
2. 选择角色、场景、音乐
3. 在输入框中输入对话，按回车发送
4. AI会根据你的输入生成回复

## v6 核心亮点

### 虚拟App平台

**位置**：导航栏 → 聊天/论坛/邮箱/设置/美化/自定义App

- **微信样式聊天**：与NPC进行即时对话，支持发送文字、表情
- **论坛系统**：4大板块（世界观讨论/角色交流/攻略分享/水区闲聊），发帖/回帖/点赞
- **邮箱系统**：收发邮件、已读标记、回复功能，NPC可自动发邮件
- **设置中心**：账号信息、通知开关、主题切换、字体大小、数据导入导出
- **美化中心**：5套预设主题（墨境/深夜/樱花/森林/海洋）、自定义配色、粒子飘落效果
- **自定义App**：创建自己的虚拟App，名称/图标/颜色/描述全自定义

### 游戏系统

- **成就系统**：16个成就，分剧情/收集/社交/探索/挑战5类，自动追踪进度
- **背包系统**：5类物品（道具/装备/材料/消耗品/任务），支持使用/赠送/丢弃
- **联盟系统**：创建或加入门派，成员管理，等级显示
- **趣味功能**：骰子、每日运势、诗词生成、幸运转盘、猜谜语、起名生成器

### 君成录风格沉浸式场景

**位置**：导航栏 → 「君成录」

- **4大场景**：金銮殿（朝堂）、后宫（御花园）、长安街（街道）、书院（琴棋书画）
- **六部按钮**：吏部/户部/礼部/兵部/刑部/工部，点击跳转对应功能
- **场景切换**：下拉选择场景，背景图自动切换
- **NPC对话**：选择场景内角色进行对话

### 全模块联动（EventBridge）

v4-v6 新增**联动中枢**，所有39个模块之间可以互相通信：

- **导入→人物志**：导入角色卡后自动出现在人物志，可立即参与对话
- **世界书→运行时**：对话中自动匹配世界书关键词并注入上下文
- **地图→背景**：点击地图地点"前往"，自动切换对应背景
- **百科→世界书**：百科查询结果自动保存到世界书/记忆
- **UI DIY→运行时**：自定义的按键和按钮布局在运行时立即生效
- **自定义功能→导航**：创建的功能自动加入侧边栏导航
- **预设→全模块**：预设导入后自动分发到API/提示词/状态栏等
- **备份→全恢复**：备份恢复后所有模块状态自动同步
- **运行时↔小手机**：手机模拟器实时镜像桌面运行状态
- **背包→成就**：获得物品自动触发成就检查
- **联盟→邮件**：联盟成员可互发邮件

### 小手机模拟器

**位置**：导航栏 → 「小手机」

- **6种机型**：iPhone 14 Pro / SE / Pixel 7 / Galaxy S23 / iPad Mini / 自定义
- **缩放/旋转**：可以缩放模拟器尺寸，切换横竖屏
- **触屏交互**：支持点击、滑动的触屏交互模拟
- **联动模式**：开启后，手机模拟器与桌面运行时实时同步
- **导出App**：一键导出独立的手机版HTML文件
- **独立运行**：导出的HTML可在手机上直接打开，无需服务器

### PWA 应用

**位置**：导航栏 → 「PWA应用」

- **安装到主屏幕**：像普通App一样从主屏幕启动
- **离线运行**：Service Worker缓存页面，断网也能打开
- **自定义配置**：应用名称、描述、主题色、图标、显示模式
- **多平台支持**：iOS Safari、Android Chrome、桌面Chrome/Edge
- **详细安装指南**：每个平台都有图文步骤说明

## Git部署教程

### GitHub Pages（推荐，免费）

1. 在 GitHub 创建新仓库（如 `my-visual-novel`）
2. 将 `ai-visual-novel-v6` 文件夹内的所有文件上传到仓库
3. 进入仓库 Settings → Pages
4. Source 选择 "Deploy from a branch"
5. Branch 选择 "main"，文件夹选 "/ (root)"
6. 等待1分钟，访问 `https://你的用户名.github.io/my-visual-novel`

### 手机Git部署

1. 在手机上安装 Git 客户端（如 Termux / Working Copy）
2. 克隆仓库：`git clone https://github.com/你的用户名/my-visual-novel.git`
3. 修改文件后提交：`git add . && git commit -m "更新" && git push`
4. GitHub Pages 会自动更新

### PWA安装（手机端）

**iOS Safari：**
1. 用 Safari 打开部署好的页面
2. 点击底部「分享」按钮
3. 选择「添加到主屏幕」→「添加」

**Android Chrome：**
1. 用 Chrome 打开部署好的页面
2. 点击右上角「⋮」菜单
3. 选择「添加到主屏幕」或「安装应用」

### 修改指南

**改导航栏名称/顺序：**
- 打开 `js/app-v4.js`
- 找到 `NAV_ITEMS` 数组
- 修改 `label` 或调整数组顺序

**改颜色主题：**
- 打开 `css/theme.css`
- 找到 `:root` 中的颜色变量
- 修改 `--color-primary`、`--color-gold`、`--bg-body`

**添加新页面：**
1. 在 `index.html` 添加 `<section class="page-view" id="page-xxx">`
2. 创建 `js/xxx.js`，定义模块对象，包含 `init()` 和 `onEnter()`
3. 在 `app-v4.js` 的 `NAV_ITEMS` 和 `callbacks` 中添加
4. 在 `index.html` 底部添加 `<script src="js/xxx.js">`

**修改AI提示词：**
- 打开 `js/prompts.js`
- 修改 `getDefaults()` 中的模板

**添加角色字段：**
- 打开 `js/npc-v3.js`
- 在 `BUILTIN_FIELDS` 数组中添加新字段

**修改君成录场景：**
- 打开 `js/portal.js`
- 修改 `SCENES` 数组中的场景名称、按钮和跳转目标

**添加新成就：**
- 打开 `js/achievement.js`
- 在 `ACHIEVEMENTS` 数组中添加新成就对象

**添加新物品类型：**
- 打开 `js/inventory.js`
- 在 `CATEGORIES` 数组中添加新分类

## 注意事项

1. **数据存储**：所有数据保存在浏览器本地，请定期使用「备份管理」或「设置→导出数据」导出备份文件。
2. **图片大小**：单张图片建议不超过2MB，避免IndexedDB存储失败。
3. **API调用**：对话会消耗API额度，请合理设置 Temperature 和 Max Tokens。
4. **移动端**：支持手机浏览器访问，建议在桌面端进行复杂的编辑操作。
5. **兼容性**：需要现代浏览器（Chrome/Edge/Safari/Firefox最新版）。
6. **PWA离线**：Service Worker会缓存页面，但首次使用需要联网加载所有资源。
7. **小手机**：模拟器在桌面端运行，导出的App可在手机上独立打开。
8. **君成录场景**：场景背景图需要自行准备，默认使用渐变背景。
